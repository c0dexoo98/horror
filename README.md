# HOLLOW VALE | درهٔ توخالی — HollowEngine edition

بازی ترسناک بقا. **نسخهٔ Three.js حذف شد** — بازی حالا کاملاً روی [HollowEngine 2](https://github.com/c0dexoo98/HollowEngine)
اجرا می‌شود: موتور سه‌بعدی از صفر با زبان اسکریپت OOP، فیزیک، چند-نور، سایه، مه، وینیت و فونت HUD — جاوا خالص، بدون هیچ وابستگی.

## چی هست

کمپین ۷ مأموریت با پایان‌بازی قطعی: یادداشت → کلید چاه → کلیسا → نامه → ۵ طلسم مومی →
آیین طرد بر مذبح → **مادر** (۳ فلاش + حمله) → فرار از دروازهٔ جنوبی.
غول‌ها صدا را می‌شنوند، چراغ‌قوه باتری می‌سوزاند، ضربه از پشت ×۳ است، و باتِ قطعی خودِ بازی
کل کمپین را تا `ENDING: ESCAPED` می‌بازد — همان seed، همان نتیجه، هر بار.

## اجرا

```bash
# کل کمپین هدلس (قطعی):
../hollowengine/hollow run game --frames 6500

# ادیتور و حالت بازی با کیبورد (F5):
../hollowengine/hollow editor game

# تست‌های بازی:
bash game/verify.sh     # باید ALL GREEN بماند
```

جزئیات کامل: [game/README.md](game/README.md) — کنترل‌ها، سیستم‌ها، ساختار صحنه.

## اندروید

**[دانلود hollow-vale.apk](../../releases/latest/download/hollow-vale.apk)** — نسخهٔ ۱.۱ (حدود ۷۰KB)، Android 8+

- نصب: فایل را دانلود و باز کنید (Allow unknown sources)؛ امضای debug برای نصب شخصی است.
- کنترل‌های لمسی: `RESTART` / `PAUSE` / `SPEED ×1→×2→×4→×12` / `LOG` (گزارش مأموریت‌ها).
- چرا فقط ۷۰KB؟ چون هیچ کتابخانهٔ خارجی وجود ندارد — کل موتور سه‌بعدی (رستر، فیزیک، نور، مه، فونت HUD)
  و کل کمپین، جاوا خالص و assetهای متنی‌اند. همین APK با `runtime-android/build.sh` در موتور ساخته می‌شود
  (javac → D8 → aapt2 → apksigner، بدون gradle).
- کمپین قطعی است: همان اجرای دسکتاپ، در ×12 حدود ۶ دقیقه تا `ENDING: ESCAPED`.

## وب

صفحهٔ `src/app/page.tsx` حالا یک لندینگ استاتیک با اسکرین‌شات‌های رندرشدهٔ خود موتور است
(`public/vale-*.png`) — بدون Three.js، بدون WebGL. نسخهٔ اندروید native (پوشهٔ `hollowvale-native`)
دست‌نخورده مانده است.
