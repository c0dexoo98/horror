# HOLLOW VALE — HollowEngine edition

بازی ترسناک بقا — **بازنویسی کامل روی موتور HollowEngine 2** (جاوا خالص، بدون Three.js، بدون وابستگی وب).
نسخهٔ قدیمی Three.js از ریپو حذف شده است (تاریخچهٔ گیت نگه می‌دارد).

## اجرا

```bash
# کمپین کامل به‌صورت هدلس — بات قطعی بازی را تا ESCAPED می‌بازد (~۶۵۰۰ فریم)
../hollowengine/hollow run game --frames 6500

# فریم رندرشده با HUD
../hollowengine/hollow render game --frames 60 --out frame.png

# ادیتور + حالت بازی واقعی
../hollowengine/hollow editor game     # سپس F5
```

## کنترل‌ها (حالت Play در ادیتور)

| کلید | عمل |
|---|---|
| WASD / جهت‌ها | حرکت |
| Q | دویدن (صدا می‌دهد — غول‌ها می‌شنوند) |
| C | خزیدن بی‌صدا |
| E | عمل (برداشتن/در/مذبح) |
| F | چاقو (ضربه از پشت = ×۳) |
| G | شلیک هفت‌تیر |
| R | پرکردن خشاب |
| T | چراغ‌قوه (باتری مصرف می‌کند) |
| X | فلاش دوربین — مادر را کور می‌کند (۳ بار) |

## ساختار

```
game/

├── gen_scene.py        ← مولد قطعی صحنه
├── vale.hs             ← کل بازی: کلاس‌های Ghoul/Mother، ۷ مأموریت، بات، HUD
└── verify.sh           ← چک‌های بازی
```

## کمپین (۷ مأموریت + پایان)

1. یادداشت کنار جسدت را بخوان
2. کلید زنگ‌زده روی چاه
3. در کلیسا را باز کن
4. نامهٔ داخل کلیسا
5. پنج طلسم مومی (اطراف روستا — غول‌ها می‌شنوند اگر بدوی)
6. آیین طرد بر مذبح → **مادر تجلی می‌کند** → ۳ بار با فلاش کورش کن → نابودش کن
7. فرار از دروازهٔ جنوبی → **ENDING: ESCAPED** (یا با ترس/جراحت بمیر → **DARKNESS**)
