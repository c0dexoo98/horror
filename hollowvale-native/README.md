# HOLLOW VALE | درهٔ توخالی — v4.1

بازی ترسناک تک‌نفرهٔ اندروید، کاملاً **جاوا خالص + Android SDK** — بدون WebView، بدون Three.js، بدون هیچ تکنولوژی وب.

## موتور اختصاصی (HollowVale Engine)
- **Raycast DDA** دست‌نویس در GLSL ES 2.0 (۴۸×۴۰ سل، درهای کشویی، نور دینامیک)
- تا **۱۲ منبع نور** همزمان: مشعل سوسوزن، شمع، نور محراب، مه‌تاب
- **چراغ‌قوه با مخروط نور** + باتری + سوسوی واقع‌گرایانه
- **مه حجمی**، رعدوبرق پویا، سایه‌پردازی لبه‌ای
- **پس‌پردازش PS1**: آپ‌اسکیل Nearest، دیترِ Bayer 4×4، کوانتیز ۵-بیت، دانهٔ فیلم، وینیت
- افکت‌های روان‌گسیختگی (Sanity FX)، لرزش ضربه، فلاش دوربین

- 🎬 **اسپلش‌اسکرین ویدیویی ترسناک** با نام بازی ( intro.mp4 ) + میان‌پردهٔ پایان

- 🗣️ **دیالوگ انتخاب‌گزینه‌ای** (فروشندهٔ مرموز، محراب، رادیو، آینه)

- 👻 **مادر**: تجلی‌های مرحله‌ای، تخلیهٔ روان با نگاه، خنثی‌سازی با دوربین

- 🎛️ **شخصی‌سازی کامل لمس**: جابه‌جایی، اندازه، شفافیت دکمه‌ها
- 🎚️ تنظیمات: حساسیت، صداها (کلی/موسیقی/جلوه)، ۳ سطح کیفیت، مه، دانهٔ فیلم، برعکس‌کردن نگاه، لرزش، FPS

## ساخت
```bash
./gradlew assembleRelease   # JDK 17+، Android SDK 34
```
APK خروجی: `app/build/outputs/apk/release/app-release.apk`

## تست منطق (بدون اندروید)
```bash
javac -d out app/src/main/java/ir/hollowvale/game/*.java test/TestMain.java
java -cp out TestMain        # ۷۱/۷۱ ✓
```
