## 🎮 داستان و هدف

سال ۱۸۹۷ — دهکده‌ی **Hollow Vale** به زنگی پاسخ داد که هرگز نباید به صدا می‌آمد.
**«شبان»** (The Shepherd) با فانوسش در کوچه‌ها پرسه می‌زند و **صدای قدم‌های تو را می‌شنود**.

**کوئست‌های اصلی (۶ فصل):**
1. 🔑 کلید کلیسا را از گاوداری قدیمی پیدا کن
2. 📜 نامه‌ی کشیش را در کلیسا بخوان
3. 🔥 سه منقل را در خانه‌ها روشن کن (خانه‌ی میلر، مزرعه، نمازخانه)
4. 🪣 با دستکول چاه، **تعویقه‌ی نفرین‌شده** را از اعماق بیرون بکش
5. ⚰️ تعویقه را روی محراب قبرستان بگذار و کلید آهنی بگیر
6. 🚪 دروازه‌ی جنگل را باز کن و **فرار کن!**

**کوئست‌های جانبی:**
- 🔫 **تفنگ شکاری هانتر**: قنداق (گاوداری) + لوله (کلبه‌ی شکارچی) → مونتاژ در کارگاه → با یک شلیک شبان را زمین می‌زند!
- 💊 **درمان دکتر**: ۳ شاخه‌ی شب‌بو (گلخانه، قبرستان، لبه‌ی جنگل) → هاون کلینیک → قرص و باند جایزه بگیر
- 📖 **نجواهای مردگان**: هر ۸ یادداشت پخش‌شده در روستا را بخوان → مهمات و قرص جایزه + پایان داستانی

## 🌐 مولتی‌پلیر (با IP)

۳ روش داری:

### روش ۱ — سرور آنلاین آماده (ساده‌ترین)
بازی نسخه‌ی مرورگر را از **لینک پیش‌نمایشی** که برایتان فرستاده شده باز کنید:
- برید `Multiplayer` → اسم بگذارید → `Create Room`
- **کد ۴ حرفی** را برای دوستانتان بفرستید
- دوستان از همان لینک، `Join Room` می‌زنند و کد را وارد می‌کنند

### روش ۲ — سرور روی کامپیوتر خودتان (LAN / اینترنت)
```
cd hollowvale-server
npm install
npm start
```
- در بازی: `Settings` → **Multiplayer server** → بنویسید: `ws://IP-کامپیوتر-شما:8787`
- IP خودتان را با `ipconfig` (ویندوز) یا `ip addr` (لینوکس/مک) پیدا کنید
- دوستان همین IP را در تنظیماتشان وارد کنند و با کد اتاق وصل شوند
- اگر پشت روتر هستید، پورت `8787` را Forward کنید تا دوستان از اینترنت بیایند

### روش ۳ — سرور روی گوشی (Termux)
۱. اپ [Termux](https://f-droid.org/packages/com.termux/) را نصب کنید
۲. `pkg install nodejs` و بعد فایل پوشه‌ی `hollowvale-server` را به گوشی منتقل کنید
۳. `npm install && npm start` → حالا IP گوشی‌تان (`ws://192.168.x.x:8787`) سرور دوستان است (همه در یک وای‌فای)

**دو حالت بازی:**
- 🤝 **Co-op** — همه با هم کوئست‌ها را پیش می‌برید، شبان هوش مصنوعی است، هم‌تیمی‌افتاده را احیا کنید
- 👹 **Shepherd vs Survivors** — یکی از شما **خودِ شبان** می‌شود و بقیه باید زنده فرار کنند! (تایمر ۱۲ دقیقه تا سپیده‌دم)

## 💡 نکات بقا

- 🏃 **دویدن = مرگ.** شبان صدا را دنبال می‌کند. شنل بزن یا آرام قدم بزن.
- 🔦 چراغ‌قوه دید میدهد ولی **تو را از دور لو می‌دهد**. در تاریکی مطلق «وحشت» بالا می‌رود و توهم می‌بینی...
- 💊 قرص وحشت را کم می‌کند؛ باند جانی برمی‌گرداند؛ باتری جاگذاری کن که چراغ خاموش نشود
- 🔫 گلوله شبان را **لنگ** می‌کند (نمی‌میرد!) — با هفت‌تیر وقت بخر، با تفنگ شکاری زمینش بزن
- 💣 **نارنجک صوتی** شبان را ۶ ثانیه زمین نگه می‌دارد و صدای تو را می‌پوشاند
- ⚰️ قبرستان و چاه نقطه‌های خطرند — قبل از آنجا مهمات و باند جمع کن
