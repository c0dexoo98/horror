# HOLLOW VALE — نسخه بومی اندروید (v2.0-native)

این نسخهٔ **کاملاً جدید** بازی است: دیگر WebView و Three.js در کار نیست.
کل بازی با یک **موتور اختصاصی جاوا برای اندروید** از صفر ساخته شده
(موتور Raycast دست‌نویس + رندر Canvas + ذخیره‌سازی SurfaceView).

## نصب
1. فایل `HollowVale-Native.apk` را به گوشی بفرستید.
2. روی فایل بزنید؛ اگر پرسید، اجازهٔ «نصب از منبع ناشناس» را بدهید.
3. بازی را باز کنید — به اینترنت، مجوز یا اتصال سرور نیازی نیست (کاملاً آفلاین).

## مشخصات
| مورد | مقدار |
|---|---|
| حجم APK | ~57 کیلوبایت |
| موتور | Raycaster اختصاصی جاوا (بدون WebView، بدون کتابخانهٔ خارجی) |
| حداقل اندروید | 7.0 (API 24) |
| مجوزها | هیچ! |
| اینترنت | لازم نیست |
| دارایی‌های خارجی | هیچ — همهٔ بافت‌ها، اسپرایت‌ها و صداها در لحظهٔ اجرا تولید می‌شوند |

## داستان و هدف
شهر متروکهٔ Hollow Vale، ساعت ۳ نیمه‌شب. «مادر» شکار می‌کند.
راه نجات: خواندن یادداشت جاده → یافتن کلید زنگ‌زده در قبرستان →
بازکردن کلیسا → جمع‌آوری ۵ طلسم مومی → برگزاری مراسم دورسازی در محراب →
فرار از دروازهٔ جنوبی.

## کنترل‌ها
- **نیمهٔ چپ صفحه**: کشیدن = حرکت (تا لبه = دویدن، صدای زیاد!)
- **نیمهٔ راست**: کشیدن = نگاه کردن
- **USE**: برداشتن / بازکردن در / خواندن / مراسم (نگه‌دارید)
- **LIGHT**: چراغ‌قوه (باتری مصرف می‌کند؛ خاموشی = ترس بیشتر)
- **SNEAK**: راه‌رفتن بی‌صدا
- **MAP**: نقشهٔ کشف‌شده · **TASKS**: فهرست وظایف با تیک سبز ✓

## هوش مصنوعی «مادر»
- حالت‌ها: گشت‌زنی، تحقیق (سر و صدا می‌شنود)، تعقیب، جست‌وجو
- دویدن از ۱۳ بلوک شنیده می‌شود، راه‌رفتن از ۷ بلوک، قدم‌زدن پنهانی تقریباً هیچ
- چراغ‌روشنِ شما از دورتر دیده می‌شود؛ پشت دیوار نمی‌تواند ببیند (Raycast)
- درهای چوبی را خودش باز می‌کند... با صدای جیرجیر
- ۳ بار گرفتن شما = پایان بازی

## سیستم‌ها
سلامت (۳ ضربه)، استقامت برای دویدن، باتری چراغ‌قوه، ترس (افکت ویگنت قرمز +
ضربان قلب تندتر + شنیده‌شدن توسط هیولا)، رعد و برق، مه، دانه‌های فیلم،
موسیقی دوگانه (آرام/تعقیب)، نقشهٔ کشف‌شده، قطب‌نمای وظیفه.

## اجرای سرور/ساخت از سورس
```bash
# ساخت دوبارهٔ APK (بدون gradle):
bash scripts/build_apk_native.sh
# تست منطق بازی روی JVM (۴۰ تست):
javac -d /tmp/t src/ir/hollowvale/game/*.java test/TestMain.java && java -cp /tmp/t TestMain
```
