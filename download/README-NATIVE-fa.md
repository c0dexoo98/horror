# HOLLOW VALE — نسخه بومی اندروید (v2.1-native · رفع باگ)

این نسخهٔ **کاملاً جدید** بازی است: دیگر WebView و Three.js در کار نیست.
کل بازی با یک **موتور اختصاصی جاوا برای اندروید** از صفر ساخته شده
(موتور Raycast دست‌نویس + رندر Canvas + ذخیره‌سازی SurfaceView).

## تغییرات v2.1 (رفع کامل باگ‌ها)
- **رفع فریز شدن بازی**: اگر خطایی در حلقهٔ بازی رخ می‌داد، ترد بازی برای همیشه می‌مُرد و صفحه یخ می‌زد — حالا خطاها گرفته می‌شود و بازی ادامه می‌دهد.
- **رفع رقابت رندرر**: تغییر کیفیت خودکار (auto-perf) هنگام رندر می‌توانست فریم‌های سیاه/کرش ایجاد کند — الان تغییر مقیاس فقط داخل ترد بازی اعمال می‌شود.
- **دکمهٔ PAUSE جدید** روی HUD (بالا-چپ، کنار نوار باتری) — قبلاً فقط با دکمهٔ Back سیستم میشد.
- **بستن لیست وظایف با لمس هر نقطه** — قبلاً فقط دکمهٔ TASKS کار می‌کرد (متن «tap anywhere» دروغ می‌گفت).
- **اصلاح صدا**: خاموش‌کردن SOUND حالا واقعاً همهٔ صداها (ضربان قلب، موسیقی محیط، موسیقی تعقیب) را قطع می‌کند؛ موسیقی تعقیب بعد از مرگ/برد/توقف محو می‌شود (قبلاً ادامه پیدا می‌کرد).
- **پایداری صدا**: اگر بارگذاری یکی از فایل‌های صوتی گم می‌شد، کل صدا از کار می‌افتاد — الان watchdog جایگزین دارد.
- **بهبود کارایی AI هیولا**: در حالت گشت‌زنی/جست‌وجو مسیریابی BFS در هر فریم اجرا می‌شد (افت FPS و مصرف باتری) — الان محدودسازی زمانی دارد.
- **نجات هیولا از داخل در بسته** — حالت مرزی که هیولا را برای همیشه بی‌حرکت می‌کرد.
- **کش‌شدن مینی‌مپ**: ~۱۵۰۰ مستطیل‌کشی در هر فریم به کش بیت‌مپ تبدیل شد.
- **حذف تخصیص حافظه در هر فریم** در رندرر (Paint/Shader) → لگِ کمتر.
- **امضای APK حفظ شد**: نسخهٔ جدید مستقیم روی نسخهٔ قبلی نصب می‌شود (versionCode 3).
- مجموعه تست جدید استرس (۶۰هزار تیک آشوب + گشت‌زنی از هر خانهٔ نقشه) — همه سبز.

## نصب
1. فایل `HollowVale-Native.apk` را به گوشی بفرستید.
2. روی فایل بزنید؛ اگر پرسید، اجازهٔ «نصب از منبع ناشناس» را بدهید.
3. بازی را باز کنید — به اینترنت، مجوز یا اتصال سرور نیازی نیست (کاملاً آفلاین).

## داستان و هدف
شهر متروکهٔ Hollow Vale، ساعت ۳ نیمه‌شب. «مادر» شکار می‌کند.
راه نجات: خواندن یادداشت جاده → یافتن کلید زنگ‌زده در قبرستان →
بازکردن کلیسا → جمع‌آوری ۵ طلسم مومی → برگزاری مراسم دورسازی در محراب →
فرار از دروازهٔ جنوبی.

## کنترل‌ها
- **نیمهٔ چپ صفحه**: کشیدن = حرکت (تا لبه = دویدن، صدای زیاد!)
- **نیمهٔ راست**: کشیدن = نگاه کردن
- **USE**: برداشتن / بازکردن در / خواندن / مراسم (نگه‌دارید)
- **LIGHT**: چراغ‌قوه (باتری مصرف می‌کند؛ خاموشی = ترس بیشتر)
- **SNEAK**: راه‌رفتن بی‌صدا
- **MAP**: نقشهٔ کشف‌شده · **TASKS**: فهرست وظایف با تیک سبز ✓ (لمس هر نقطه = بستن)
- **❚❚ (PAUSE)**: بالا-چپ صفحه، کنار نوارها

## هوش مصنوعی «مادر»
- حالت‌ها: گشت‌زنی، تحقیق (سر و صدا می‌شنود)، تعقیب، جست‌وجو
- دویدن از ۱۳ بلوک شنیده می‌شود، راه‌رفتن از ۷ بلوک، قدم‌زدن پنهانی تقریباً هیچ
- چراغ‌روشنِ شما از دورتر دیده می‌شود؛ پشت دیوار نمی‌تواند ببیند (Raycast)
- درهای چوبی را خودش باز می‌کند... با صدای جیرجیر
- ۳ بار گرفتن شما = پایان بازی

## سیستم‌ها
سلامت (۳ ضربه)، استقامت برای دویدن، باتری چراغ‌قوه، ترس (افکت ویگنت قرمز +
ضربان قلب تندتر + شنیده‌شدن توسط هیولا)، رعد و برق، مه، دانه‌های فیلم،
موسیقی دوگانه (آرام/تعقیب)، نقشهٔ کشف‌شده، قطب‌نمای وظیفه.

## اجرای سرور/ساخت از سورس
```bash
# ساخت دوبارهٔ APK (بدون gradle):
bash scripts/build_apk_native.sh
# تست منطق بازی روی JVM (۴۰ تست):
javac -d /tmp/t src/ir/hollowvale/game/*.java test/TestMain.java && java -cp /tmp/t TestMain
# تست استرس (۶۰هزار تیک آشوب + گشت‌زنی هیولا از هر خانه):
javac -d /tmp/t src/ir/hollowvale/game/*.java test/StressMain.java && java -cp /tmp/t StressMain
```
